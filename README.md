# 📚 Research Collector

> Firefox-расширение для сохранения цитат и источников прямо во время чтения — без переключения между вкладками и приложениями.

Создавайте отдельные **сессии** под каждую работу, сохраняйте выделенные участки текста с автоматической привязкой к источнику, экспортируйте список цитат одним кликом.

---

## Возможности

- **Контекстное меню** — выделите текст, ПКМ → сохранить. URL и заголовок страницы подставляются автоматически
- **Сессии** — отдельная история для каждой работы (диплом, статья, реферат), переключение в один клик
- **Боковая панель** — полный список цитат с поиском, не перекрывает страницу
- **Экспорт** — в JSON (полная структура) или TXT (нумерованный список источников для вставки в текст)
- **Тост-уведомление** — подтверждение сохранения прямо на странице
- Все данные хранятся локально в браузере, никуда не отправляются

## Скриншоты

| Popup                                     | Боковая панель                         |
| ----------------------------------------- | -------------------------------------- |
| Быстрое добавление, смена сессии, экспорт | Все цитаты, поиск, управление сессиями |

## Установка

### Вариант 1 — Временная (для разработки и тестирования)

Расширение загружается напрямую из папки, без сборки. Работает до перезапуска браузера.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/research-collector.git
   cd research-collector
   ```

2. Откройте Firefox и перейдите на страницу:

   ```
   about:debugging
   ```

3. Нажмите **Этот Firefox** → **Загрузить временное дополнение** → выберите `manifest.json` из папки проекта.

После перезапуска браузера повторите шаг 3.

### Вариант 2 — Постоянная (подписанный XPI)

Попросите у меня расширение.

## Разработка

### Структура проекта

```
research-collector/
│
├── manifest.json                   ← конфигурация расширения (точка входа Firefox)
│
├── background/
│   └── background.js               ← вся бизнес-логика: хранилище, контекстное
│                                     меню, экспорт, обработка сообщений
│
├── content/
│   └── content.js                  ← внедряется в страницы: тост-уведомление
│                                     при сохранении цитаты
│
├── popup/
│   ├── popup.html                  ← мини-панель при клике на иконку в тулбаре
│   ├── popup.css
│   └── popup.js
│
├── sidebar/
│   ├── sidebar.html                ← боковая панель: все сессии и цитаты
│   ├── sidebar.css
│   └── sidebar.js
│
├── icons/
│   ├── icon-48.png
│   └── icon-96.png
│
├── .vscode/
│   └── launch.json                 ← запуск Firefox с расширением через F5
│
├── .eslintrc.json                  ← ESLint с поддержкой browser.* API
├── .prettierrc                     ← настройки форматирования
└── research-collector.code-workspace
```

### Настройка VS Code

1. Установите рекомендуемые расширения (VS Code предложит автоматически при открытии папки):

   - [Firefox Debugger](https://marketplace.visualstudio.com/items?itemName=firefox-devtools.vscode-firefox-debug) — отладка прямо из редактора
   - [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) — линтер
   - [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) — форматирование

2. Откройте проект как workspace:

   ```
   File → Open Workspace from File → research-collector.code-workspace
   ```

3. Нажмите `F5` — Firefox откроется с уже загруженным расширением и подключённым отладчиком.

### Горячая перезагрузка

При изменении файлов нажмите **Перезагрузить** на странице `about:debugging` рядом с расширением. Изменения в `background.js` требуют полной перезагрузки; `popup` и `sidebar` обновляются при следующем открытии.

### Архитектура

Расширение построено на [WebExtensions API](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions) без внешних зависимостей и сборщиков.

```
Страница браузера
  └─ content.js          (показывает тост при сохранении)
       ↕ messages
background.js            (хранит данные, слушает события)
       ↕ messages
  ├─ popup.js            (быстрые действия из тулбара)
  └─ sidebar.js          (полный UI управления)
```

Все компоненты общаются через `browser.runtime.sendMessage`. Данные хранятся в `browser.storage.local` (до 10 МБ).

## Формат данных

```json
{
  "sessions": {
    "session_1719482400000": {
      "id": "session_1719482400000",
      "name": "Диплом — глава 2",
      "createdAt": "2026-06-27T10:00:00.000Z",
      "entries": [
        {
          "id": "entry_1719482460000",
          "text": "Выделенный участок текста со страницы",
          "url": "https://example.com/article",
          "pageTitle": "Название страницы",
          "savedAt": "2026-06-27T10:01:00.000Z",
          "note": ""
        }
      ]
    }
  },
  "activeSession": "session_1719482400000"
}
```

## Права доступа

| Разрешение     | Зачем                                                    |
| -------------- | -------------------------------------------------------- |
| `storage`      | Хранение сессий и цитат локально                         |
| `activeTab`    | Получение URL и заголовка текущей вкладки при сохранении |
| `contextMenus` | Пункт «Сохранить цитату» в контекстном меню              |
| `downloads`    | Экспорт файлов JSON и TXT                                |
| `tabs`         | Отправка тост-уведомления на страницу после сохранения   |

Расширение не имеет доступа к содержимому страниц без явного действия пользователя и не передаёт никакие данные на внешние серверы.

## Конфиденциальность

Research Collector **не собирает и не передаёт никаких данных**. Все цитаты и сессии хранятся исключительно в `browser.storage.local` на вашем устройстве и никуда не отправляются. Подробнее — в [PRIVACY.md](PRIVACY.md).
