# Research Collector

Firefox extension for saving quotes and sources while writing research papers and essays.

## Features

- Save quotes via right-click context menu
- Optional title and comment for each quote
- Sessions (projects) with color coding
- Sidebar with search and preview
- Text Fragment links — clicking a source jumps to the exact quote on the page
- Export to JSON and TXT
- All data stored locally, no network requests
