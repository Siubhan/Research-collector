# Changelog

## [2.1.1] — 2026-10-10

### Исправлено
- Кнопка «Перенести…» не открывала окно выбора сессии (конфликт id в HTML)
- Якорь Text Fragment (#:~:text=) работает корректно при переходе к источнику
- Инлайн-обработчик onerror на favicon заменён на JS (предупреждение AMO lint)
- Добавлено поле data_collection_permissions в manifest (требование Firefox AMO)
- Кнопки в модальном окне цитаты расположены вертикально для удобства на узком экране
- Кнопка удаления цитаты возвращена на карточку
- Цитата появляется в сайдбаре сразу после сохранения (без перезагрузки панели)
- Цвет цитаты сохраняется корректно

## [2.1.0] — 2026-10-10

### Добавлено
- Цвет цитаты: выбор из фиксированной палитры в модалке редактирования, акцентная полоска на карточке отражает цвет цитаты (или цвет сессии если цвет не задан)
- Фильтрация по цвету: цветные кружки над списком цитат, появляются только при наличии цветных цитат
- Сортировка цитат: по дате (новые/старые), по источнику, по цвету
- Перенос цитаты в другую сессию через кнопку «Перенести…» в модалке
- Favicon источника на карточке цитаты
- Экспорт в Markdown (.md): цитаты как blockquote, источники как ссылки

## [2.0.2] — 2026-10-10

### Добавлено
- Text Fragments для веб-страниц: при сохранении цитаты через ПКМ URL автоматически дополняется фрагментом `#:~:text=...` — клик по источнику в sidebar открывает страницу и прокручивает к нужному месту
- PDF anchor: если PDF открыт в браузере с `#page=N` в URL, этот якорь сохраняется вместе с цитатой

## [2.0.1a] — 2026-10-10

### Добавлено
- Необязательный заголовок для цитаты: отображается на карточке и включается в TXT-экспорт
- Иконка тигрёнка заменила эмодзи 📚 в шапке popup и sidebar

### Исправлено
- Иконка расширения корректно обрезается по контенту и масштабируется без полей

## [2.0.0] — 2026-07-05

### Добавлено
- Цвет проекта: выбор из палитры при создании и редактировании работы
- Переименование сессий через модальное окно
- Комментарии к цитатам: поле в модалке редактирования, превью на карточке, включается в экспорт TXT
- Модальное окно предпросмотра и редактирования цитаты: правка текста и комментария, переход к источнику, удаление
- Поиск по комментариям в боковой панели
- Индикатор цвета сессии в popup и sidebar
- Gecko ID расширения в manifest.json

### Изменено
- Удаление сессий доступно для всех, включая активную — с автопереключением на следующую
- Карточки цитат подсвечиваются цветом текущего проекта
- Формат данных: добавлены поля `color` и `comment`
- Лицензия изменена с MIT на Apache License 2.0

### Удалено
- Функционал синхронизации с папкой (File System Access API не поддерживается в Firefox)

## [1.0.0] — 2026-06-27

### Добавлено
- Сохранение цитат через контекстное меню (ПКМ на выделенном тексте)
- Быстрое добавление цитат через popup в тулбаре
- Боковая панель с полным списком цитат и поиском
- Управление сессиями: создание, переключение, удаление
- Экспорт текущей сессии в JSON и TXT
- Тост-уведомление на странице при сохранении цитаты
- Конфигурация VS Code с отладчиком Firefox
